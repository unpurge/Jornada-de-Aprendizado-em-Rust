# Diferenças para a Linguagem C:
- Percebi uma mera semelhança para receber valor, em C, é: "scanf("%d", &variável);"
Já em Rust, "io::stdin().read_line(&mut variável) ...", ambos demonstram usar ponteiro, dentro de parênteses,
fora que, em rust usa uma função para poder pegar, depois um "scanf".
A maior diferença analisada, é que em Rust, devemos sempre receber o valor como string, e apenas depois modificar o valor como quer. 
Em C, ja fazemos isso de uma vez, como uma sintaxe bem mais curta.
Mas depois, Rust ganha de lavada, apenas um ".trim()", ja faz oque precisaria de uma longa sintaxe de strcspn para retirar o "\n".
Fora que em C, não conseguiámos usar a mesma variável recebendo 2 tipos de valores em um unico processo do código. Interessante e otimizado!
